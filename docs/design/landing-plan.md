# Landing page plan

The site becomes an overview landing page plus one in-depth page per day. Everything is still generated by `pipeline/site.py` from files the pipeline already writes: no extra LLM calls.

## Structure

```
site/index.html            landing: hero + overview across all days
site/days/<date>.html      one page per day (the current in-depth page)
site/assets/logo.png       the white helix logo on black (256px)
```

Day pages get a slim header (logo + "← Overview") and previous/next day links.

## Look

- Near-black base, one accent: deep crimson (as in `docs/design/hero-reference.webp`). Semantic rating colours stay as they are.
- Hero is always dark. Day pages and the reading-heavy sections can follow the viewer's light/dark preference.
- Keep it simple. Must work on phones (about 400px wide): stats stack below, nav collapses to the logo plus a short link row, no horizontal scrolling.

## Landing page sections

1. **Hero** (inspired by the reference image, not copied):
   - Moving background: a slow **lava-lamp** effect, crimson blobs that drift and merge on near-black. Simple: CSS animated blurred radial blobs with a goo/contrast filter, or one small canvas script. Respect `prefers-reduced-motion` (static frame).
   - Logo (`assets/logo.png`) with the name "GENE RESEARCH"; small nav: Today, Watchlist, Track record, Archive, GitHub (https://github.com/neozhixuan/gene-research).
   - **No big headline.** One short line of description (daily AI-bottleneck research diary; worldview by Claude, verification by TradingAgents on Gemini).
   - Pill button "Read today's analysis →" linking to the latest day.
   - Stats column (right on desktop, below on mobile), computed from data: days of research, stocks analysed, active watchlist, average return vs QQQ of new picks.
2. **Today at a glance**: latest headline, each stock run that day with its final rating chip and the own-it / don't-own-it action (`ACTIONS` in `pipeline/common.py`).
3. **Watchlist board**: a card per active name: rating history as coloured dots, return since added, vs QQQ, current action. Dropped names in a collapsed list with the reason.
4. **Worldview over time**: theses (rows) × days (columns), cell shade = confidence, marks for new/retired/stronger/weaker. Scrolls sideways inside its own container on mobile.
5. **Segment stance over time**: the same grid for the 11 segments (overweight / neutral / underweight).
6. **Track record**: scorecard and the picks table (move from the day page).
7. **Day cards grid**, newest first: date + weekday, headline, first ~2 lines of the regime, counts of new/stronger/weaker theses, tickers with rating chips, S&P 500 and SMH 1-day change. The whole card links to the day page.
8. **Usage**: the token usage section (move from the day page).
9. Footer: sources and "experiment, not financial advice".

## Data each section reads

- `data/worldview/<date>.json`: headline, regime, theses, segments
- `data/<date>/runs.json`, `data/<date>/agents/<T>.json`: what ran and the ratings
- `data/<date>/market.json`: S&P 500 (`^GSPC`) and `SMH` daily change
- `data/watchlist.json`, `data/tracking.json`, `data/usage.csv`
