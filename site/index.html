What one daily run uses, on average (11 runs recorded)

  • Claude: about 12 calls. Each call re-sends the whole conversation so far. Claude reads most of that back from its cache: about 932 thousand tokens per run. Cached reads are much cheaper than fresh input, but they still count towards plan limits, and they are where nearly all the volume is. Fewer steps per run is the main way to cut them.
  • Claude's own writing (the worldview, the picks and its commands): about 8 thousand tokens per run, plus about 50 thousand tokens newly stored in the cache.
  • Tonight's brief (the pre-open check, with a few web searches) is part of the Claude figures above: about $0.10 of each run at API prices, over 5 runs.
  • Gemini runs TradingAgents: about 37 calls, 155 thousand tokens in and 15 thousand tokens out per run. That is on the free Google API key and does not count against your Claude plan.
