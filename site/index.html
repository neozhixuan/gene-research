Usage

$0.60 per run at API list prices, so about $13 a month and $157 a year for weekday runs. A Claude plan doesn't bill per token; this is what the same usage would cost on the API, and the best single number for comparing runs and spotting when a change makes them more expensive. Most of it is cache reads ($0.31 a run) and cache writes ($0.20).

Share of your plan: not measured yet. Anthropic doesn't publish Claude plan limits as token counts, so this page can't work out the percentage from tokens alone. To measure it once: on claude.ai open Settings → Usage just before a daily run (19:54 Singapore time) and again after it finishes, and put the difference in plan.json as weekly_limit_pct_per_run. This section then shows your weekly and monthly share.

What one daily run uses, on average (2 runs recorded)

  • Claude: about 10 calls. Each call re-sends the whole conversation so far. Claude reads most of that back from its cache: about 1.5 million tokens per run. Cached reads are much cheaper than fresh input, but they still count towards plan limits, and they are where nearly all the volume is. Fewer steps per run is the main way to cut them.
  • Claude's own writing (the worldview, the picks and its commands): about 9 thousand tokens per run, plus about 50 thousand tokens newly stored in the cache.
  • Gemini runs TradingAgents: about 34 calls, 136 thousand tokens in and 15 thousand tokens out per run. That is on the free Google API key and does not count against your Claude plan.

A month of weekday runs (about 22) comes to roughly 33.5 million tokens of Claude cache reads and 203 thousand tokens written.
